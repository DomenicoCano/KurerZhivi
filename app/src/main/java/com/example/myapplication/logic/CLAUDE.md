# logic/

Чистая бизнес-логика без Android-зависимостей (кроме `Color` из Compose) — всё покрыто тестами в `app/src/test/.../LogicTest.kt`; при правках запускайте их.

- `Scoring.kt` — `calculateScore100` (баллы), АКБ (`calculateBatteryDropPercent` — потеря должна монотонно расти с похолоданием, это проверяется тестом), калории, рекомендации по экипировке.
- `DemandLogic.kt` — давление, праздники (Чёрная пятница = последняя пятница ноября), перенос ЗП на пятницу, «горячие зоны», тихие часы, SHA-256 пароля.
- `Analytics.kt` — личная аналитика по сменам (день/неделя/месяц, лучшие дни, ₽/км, норма в день до цели), налог `taxFor`, прогноз `monthForecast`, сравнение сервисов `serviceStats`, `elapsedHours` для таймера, CSV для Excel `shiftsToCsv` (`;`, десятичная запятая, BOM).

Функции принимают `Calendar`/`nowMs` параметром — для детерминированных тестов не вызывайте `Calendar.getInstance()` внутри новых функций без параметра по умолчанию.
- `Rhythm.kt` — суточный ритм спроса (будни/выходные). У каждого интервала есть поле `basis` (исследование или «оценка без измерений»); не добавляйте числа и утверждения без источника. Облачность в баллах намеренно не учитывается — данных нет.
- `Personal.kt` — персональная калибровка: ₽/ч пользователя по времени суток, типу дня и погоде (погода берётся из `ShiftEntry.weather` на момент сохранения). Пороги `MIN_SHIFTS_TOTAL=5`, `MIN_SHIFTS_GROUP=3`: меньше — выводы не показываются. Без смен UI честно пишет «приблизительно».
