# work/

`Workers.kt` — фоновые уведомления и `sendNotification`. `AutoBackup.kt` — еженедельный бэкап в папку (SAF, `takePersistableUriPermission`), хранит 5 последних файлов; `writeBackup` вызывается и кнопкой «Сделать сейчас».

- `DailyWorker` — одноразовая задача с `initialDelay`, в конце сама себя перепланирует; в начале проверяет `getNotifEnabled()`, иначе после выключения настройки продолжила бы жить.
- `ExtremeWorker` — периодическая (30 мин): уведомляет при балле ≥85 или ≤25, не чаще раза в 3 часа и не в тихие часы (`isQuietHour`).
- Воркеры создаются WorkManager по имени класса — классы должны оставаться в `app/proguard-rules.pro` (R8).
- Фиксированные id уведомлений (`NOTIF_ID_DAILY/EXTREME`) заменяют предыдущие; тестовые уведомления из меню разработчика используют случайный id.
- Тап по уведомлению открывает `MainActivity` без `CLEAR_TASK` (не убивает открытое приложение).
